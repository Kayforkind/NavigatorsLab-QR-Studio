📖 Detailed Step-by-Step User Guide

Step 1: Type Text/URL or Pick Wi-Fi, vCard, or Email Preset · [Payload Input (#qrText) & Presets (#preWifi)]Enter any URL or text into `#qrText`, or click a structured preset button (**Wi-Fi `#preWifi`**, **vCard**, **Email**, **SMS**) to open its dedicated fields.✓ Result: Structured payload fields appear (and special characters like `;` and `\` in Wi-Fi passwords are escaped automatically).
Step 2: Apply Preset & Tune Error Correction (L / M / Q / H) · [Wi-Fi Builder (#wifiMake) & Error Correction (#ec)]Fill the preset fields (e.g., SSID `#wifiS` and Password `#wifiP`), click **Apply (`#wifiMake`)**, select Error Correction (`L`, `M`, `Q`, or `H`), and click **Generate QR (`#qrMake`)**.✓ Result: Crisp QR matrix renders immediately with module count and error-correction metadata (`#qrMeta`).
Step 3: Export Crisp Vector SVG or High-DPI PNG · [Export PNG (#qrPng) & SVG (#qrSvg)]Click **Download PNG (`#qrPng`)** for digital use or **Download SVG (`#qrSvg`)** for vector print layout in Illustrator, Figma, or InDesign.✓ Result: Direct-payload PNG or vector SVG saved locally (never expires, zero bit.ly/redirect middlemen).
Step 4: Switch to Decode Tab to Read Any QR Image Locally · [Decode Tab (#tabRead) & QR Dropzone (#qrDz)]Click **Decode QR (`#tabRead`)** and drop an image or paste a screenshot (`Ctrl+V`) onto `#qrDz`. `jsQR` decodes the raw payload string into `#qrData`.✓ Result: Inspect suspicious QR codes safely without opening untrusted URLs on your phone.

🎛️ UI Controls & Shortcuts Reference

  • Payload Box (`#qrText`) & Generate (`#qrMake`) — Encodes any text, URL, or preset string into a QR matrix.
  • Presets (`#preWifi`, vCard, Email) — Builds standards-compliant `WIFI:T:WPA;...` and `BEGIN:VCARD` payloads with RFC escaping.
  • Export PNG (`#qrPng`) & SVG (`#qrSvg`) — Saves high-resolution raster PNG or true vector SVG files.
  • Decode Tab (`#tabRead` + `#qrDz`) — Decodes QR images locally via bundled `jsQR` without a camera or network request.

💡 Pro Tips & Real-World Workflows

  • Always choose **SVG** when sending a QR code to a print shop for flyers, business cards, or banners so the module edges stay razor-sharp at any size.
  • Use Error Correction level **Q (25%)** or **H (30%)** for printed stickers outdoors so the code still scans even if scratched or smudged.
  • You can deep-link directly to a generated QR code via URL parameters: `qr.html?text=https://navigatorslab.com&ec=H`.
